Klasse vs. Objekt vs. Referanse

Klasse

Malen / oppskriften

Beskriver felter og metoder.

public class Dog { 
    private String name;
    public Dog(String name) {
        this.name = name;
        }
    public String bark() {
        return "Voff!";
    }
}
Objekt

En konkret instans

Lages med new. Lever på heap.

Innehar:

  • Type
  • Oppførsel
  • Tilstand
  • Identitet

new Dog("Rex")
Referanse

En peker til et objekt

Mange referanser kan peke paa samme objekt.

Dog a = new Dog("Rex");
Dog b = a;
equals/hashCode

Likhet

Default equals() sammenligner referanser, ikke innhold.

Likhet: equals() og hashCode()

Default oppførsel

Dog a = new Dog("Rex");
Dog b = new Dog("Rex");

a.equals(b); // false

Sammenligner referanser (==)

Krav for likehet:

  • Reflexivitet: x.equals(x) = true
  • Symmetri: x.equals(y) = y.equals(x)
  • Transitivitet: x.equals(y) og y.equals(z) => x.equals(z)
  • Konsistens: gjentatte kall gir samme resultat
  • Null-sjekk: x.equals(null) = false

Overstyring

@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Dog d)) return false;
    return name.equals(d.name);
}

@Override
public int hashCode() {
    return name.hashCode();
}
Regel: Hvis du overstyrer equals(), må du også overstyre hashCode().

Interface og abstrakt klasse

Interface

Kontrakten

  • Kun metodesignaturer (+ default-metoder i Java 8+)
  • Ingen instansfelter
  • En klasse kan implementere mange
  • Brukes for å definere oppførsel
public interface Flyable {
void fly();
}
Abstrakt klasse

Delvis implementert

  • Kan ha felter og konkrete metoder
  • Kan ikke instansieres direkte
  • Arves med extends, en klasse kan kun utvide én klasse
  • Brukes for felles kode mellom subklasser
public abstract class Shape {
public abstract double area();
public String describe() {
return "Area: " + area();
}
}
Tommelfingerregel: Bruk interface når du definerer en kontrakt. Bruk abstrakt klasse når subklasser deler konkret kode.

Records og Enum

Record (Java 16+)

Immutable dataholder

Automatisk konstruktør, getters, equals, hashCode og toString.

public record Point(int x, int y) {}
Point p = new Point(3, 4);
p.x(); // 3
Enum

Avgrenset verdimengde

Når en variabel bare kan ha et fast sett med verdier. Dette sikrer at det ikke kan oppstå ugyldige verdier.

public enum Season {
SPRING, SUMMER, FALL, WINTER
}
Season s = Season.SUMMER;
switch(s) { case SUMMER: ... }
Record vs. vanlig klasse: Records vil være uforanderlige.

Tilgangsmodifikatorer og encapsulation

  • ->
    private - bare innen klassen.
  • ->
    protected - klassen + subklasser.
  • ->
    package-private - samme pakke.
  • ->
    public - tilgjengelig for alle.
Hvordan oppnå gyldige tilstander: Valider verdier og unngå lekking av foranderlige objekter.
