## Konsept

Gode tester sjekker **grensetilfeller** (edge cases): tom liste, én element, duplikater, ugyldige verdier. En test som bare tester «normal flyt» er utilstrekkelig — bugs gjemmer seg i kantene. Testnavnet bør beskrive _hva_ som testes og _hva_ som forventes.

## Oppgave

Bruk `TaskList` fra P1. Metoden `addTask()` er allerede testet. Du skal skrive tester for `complete()` og `getByPriority()`.

Du kan ikke kjøre testene — fokus er på innhold og logikk, ikke syntax.

### a) 3 poeng — Test complete()

Skriv minst tre meningsfylte tester for `complete()`. Husk å dekke både «happy path» og grensetilfeller.

### b) 3 poeng — Test getByPriority()

Skriv minst tre meningsfylte tester for `getByPriority()`.

## Fasit

```java
class TaskListTest {
    private ITaskList tasks;

    @BeforeEach
    void setUp() { tasks = new TaskList(); }

    // --- complete() ---

    @Test
    void completedTaskCountsAsCompleted() {
        tasks.addTask("A", Priority.LOW);
        tasks.complete("A");
        assertEquals(1, tasks.countCompleted());
    }

    @Test
    void completingNonExistentTaskThrows() {
        assertThrows(IllegalArgumentException.class,
            () -> tasks.complete("Finnes ikke"));
    }

    @Test
    void onlyCompletedTasksAreCounted() {
        tasks.addTask("A", Priority.HIGH);
        tasks.addTask("B", Priority.HIGH);
        tasks.complete("A");
        assertEquals(1, tasks.countCompleted()); // ikke 2
    }

    // --- getByPriority() ---

    @Test
    void returnsOnlyTasksWithMatchingPriority() {
        tasks.addTask("A", Priority.HIGH);
        tasks.addTask("B", Priority.LOW);
        List<String> result = tasks.getByPriority(Priority.HIGH);
        assertTrue(result.contains("A"));
        assertFalse(result.contains("B"));
    }

    @Test
    void returnsEmptyListIfNoPriorityMatch() {
        tasks.addTask("A", Priority.LOW);
        assertTrue(tasks.getByPriority(Priority.HIGH).isEmpty());
    }

    @Test
    void returnedListIsNotAffectedByExternalModification() {
        tasks.addTask("A", Priority.HIGH);
        tasks.getByPriority(Priority.HIGH).clear();
        assertEquals(1, tasks.getByPriority(Priority.HIGH).size());
    }
}
```

**Hva sensor ser etter:** testene er uavhengige (`BeforeEach`), dekker ugyldige inputs, sjekker at indre tilstand ikke lekker, og testnavnene er beskrivende.
