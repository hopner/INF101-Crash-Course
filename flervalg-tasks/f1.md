## Konsept

En **klasse** er en mal (oppskrift) for å lage objekter. Et **objekt** er en konkret instans som lever i minnet.

En **referanse** er en variabel som peker på et objekt, ikke objektet selv. Vi kan ha mange referanser til samme objekt, og vi kan bytte hva en referanse peker på, så lenge den nye typen er kompatibel.

## Kode

```java
public class Animal {
    private String name;
    public Animal(String name) { this.name = name; }
    public String getName() { return name; }
}

public class Dog extends Animal {
    public Dog(String name) { super(name); }
}

// I main:
Animal a = new Dog("Rex");  // A
Dog    d = new Animal("Rex"); // B
Animal b = a;                  // C
```

## Oppgave

Sett **sant** eller **usant** på hver påstand. Hvert rett svar gir 0,5p, blank gir 0p, feil gir -0,5p.

## Påstander

- [s] En klasse er en mal; vi kan lage mange objekter fra samme klasse.
- [s] Linje A over kompilerer uten feil.
- [u] Linje B over kompilerer uten feil.
- [s] Etter linje C peker `b` og `a` på samme objekt i minnet.
- [u] Vi kan fritt bytte referansen `a` til å peke på en `String`.
- [u] `return` lager alltid en kopi av objektet som returneres.
- [s] Vi kan ha mange referanser til samme objekt.
- [u] Et objekt kan bytte klasse ved hjelp av typekasting.

## Fasit

**Sant:** klasse er mal, linje A, linje C deler objekt, mange referanser.

**Usant:** linje B (kompilerer ikke - Animal er ikke subtype av Dog), bytte til String (Java er statisk typet), return kopierer ikke objekt (bare referansen kopieres), typekasting endrer ikke klassen til objektet.
