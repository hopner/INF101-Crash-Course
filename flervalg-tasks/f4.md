## Konsept

Et **interface** definerer en kontrakt: hvilke metoder en klasse _lover_ å ha.

En **abstrakt klasse** kan ha implementerte metoder og felter, men kan ikke instansieres. En klasse kan implementere mange interfaces, men arve fra kun én klasse. Siden Java 8 kan interfaces ha `default`-metoder med implementasjon.

## Kode

```java
public interface Drawable {
    void draw(); // alle som implementerer må ha denne
    default String label() { return "Shape"; } // valgfri override
}
public abstract class Shape implements Drawable {
    protected String color; // kan ha felter
    public abstract double area(); // subklasse må implementere
    public void describe() { System.out.println(color); } // har implementasjon
}
```

## Påstander

- [s] En klasse kan implementere flere interfaces samtidig.
- [u] En abstrakt klasse kan instansieres direkte med `new`.
- [s] Et interface kan ha `default`-metoder med implementasjon (Java 8+).
- [s] En abstrakt klasse kan ha konstruktør.
- [u] Et interface kan ha instansfelter (ikke-statiske).
- [u] En klasse kan arve fra flere abstrakte klasser.
- [s] Nøkkelordet `implements` brukes for å arve fra interface.
- [s] En klasse som arver fra `Shape` over _må_ implementere `area()`, med mindre den selv er abstrakt.

## Fasit

**Sant:** implementere mange interfaces, default-metoder, abstrakt klasse kan ha konstruktør, implements-nøkkelord, må implementere area().

**Usant:** abstrakt klasse kan ikke instansieres direkte, interface kan ikke ha instansfelter, Java støtter ikke multippel klassearv.
